📱 Mobile App Integration Guide

Kisan Mitra is built mobile-first. Any Android, Flutter, or iOS app can connect to this endpoint directly using standard HTTP multipart or Base64 POST:

1. Flutter / Dart API Integration

import 'dart:io'; import 'package:http/http.dart' as http; Future diagnoseCrop(File imageFile) async { var request = http.MultipartRequest( 'POST', Uri.parse('https://your-server-ip:8000/api/v1/diagnose') ); request.files.add(await http.MultipartFile.fromPath('file', imageFile.path)); request.fields['crop'] = 'Tomato'; var response = await request.send(); return await response.stream.bytesToString(); }

2. Android (Kotlin + Retrofit)

interface KisanMitraApi { @Multipart @POST("api/v1/diagnose") suspend fun diagnoseCrop( @Part file: MultipartBody.Part, @Part("crop") crop: RequestBody ): Response }

3. 100% Offline Edge Inference (TFLite / ONNX)

The quantized ONNX model is under 3MB and can be bundled inside an Android APK or iOS app using onnxruntime-mobile or tflite_flutter to work in remote farm fields without any internet connection.
